## 📖 Overview

Interactive responsive web application developed with HTML, CSS and JavaScript following a one-page design approach.

The project demonstrates frontend development concepts including:

- Responsive design
- API integration
- DOM manipulation
- Dynamic content generation
- Event handling
- Form validation
- Interactive quizzes
- Vue.js integration

## 🛠 Technologies

- HTML5
- CSS3
- JavaScript
- Vue.js
- OpenTDB API
- QuizAPI

## 🚀 Main Features

- Responsive one-page layout
- Dynamic quiz generation using external APIs
- Automatic question translation
- Interactive animations and smooth scrolling
- Dynamic menu rendering from JSON data
- Contact form functionality
